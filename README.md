# University App UI Concept (Community)

Учебный проект мобильного приложения для студентов (на основе концепта Superior University).

## 🚀 Функционал
- Авторизация и регистрация (Login / Sign Up)
- Главный экран с расписанием и новостями
- Разделы: Курсы, Расписание, Оценки (Result) и Профиль

## 🛠 Стек технологий
- Android Studio / VS Code
- Git / GitHub для контроля версий
