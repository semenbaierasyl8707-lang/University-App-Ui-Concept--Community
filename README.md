# 🎓 UniversityApp — Мобильное приложение для управления университетской жизнью

**UniversityApp** — мобильное приложение, разработанное для студентов и преподавателей с целью упрощения доступа к академической информации и основным университетским сервисам.

Приложение позволяет просматривать расписание занятий, учебные курсы, академические результаты, новости университета, личную информацию и статистику успеваемости.

Проект разработан с использованием **React Native, Expo и TypeScript**.

## ✨ Основные возможности приложения

### 🔐 Регистрация и авторизация

- Экран входа в систему (Login).
- Регистрация новых пользователей (Register).
- Поддержка ролей Student и Teacher.
- Сохранение пользовательских данных.
- Экран восстановления пароля (Forgot Password).
- Переход между экранами авторизации и основным приложением.

*Примечание: авторизация и восстановление пароля реализованы в демонстрационном формате. Подключение полноценного серверного механизма авторизации не предусмотрено.*

### 🏠 Главная страница (Home)

- Приветствие пользователя.
- Отображение основной информации.
- Просмотр расписания занятий.
- Раздел новостей университета.
- Получение новостей ALT University через WordPress REST API.
- Отображение новостей с изображениями и описаниями.
- Возможность открыть новость для просмотра подробной информации.

### 👤 Профиль пользователя (Profile)

- Отображение личной информации пользователя.
- Имя и фамилия.
- Информация о студенте.
- Учебная группа и курс.
- Отображение фотографии профиля.
- Выбор фотографии из галереи устройства.
- Сохранение фотографии во внутренней памяти приложения.
- Сохранение информации профиля с помощью AsyncStorage.
- Сохранение выбранной фотографии после повторного запуска приложения.
- Отображение академической статистики.
- Просмотр достижений.
- Переход к настройкам и параметрам конфиденциальности.
- Возможность выхода из аккаунта.

### 📊 Академическая статистика (Profile Statistics)

В профиле реализован отдельный блок академической статистики.

Он включает:

- Количество набранных кредитов.
- Средний академический балл (GPA).
- Информацию о курсе обучения.
- Посещаемость занятий (Attendance).
- Выполнение заданий (Task & Work).
- Результаты тестирования (Quiz).

Также добавлена кнопка **Mark Attend** для демонстрации функции отметки посещаемости.

*Примечание: отображаемые значения статистики являются демонстрационными и не получаются из реальной университетской базы данных.*

### 📚 Учебные курсы (Courses)

- Отдельный экран со списком учебных курсов.
- Отображение информации о дисциплинах.
- Карточки учебных курсов.
- Переход к подробной информации о выбранном курсе.

### 📖 Подробная информация о курсе (Course Details)

- Отдельный экран для просмотра информации о выбранной дисциплине.
- Передача данных выбранного курса между экранами.
- Отображение подробной информации о курсе.

### 📅 Расписание занятий (Schedule)

- Отдельный экран расписания.
- Просмотр информации об учебных занятиях.
- Интеграция раздела расписания с основной навигацией приложения.

### 📈 Учебные результаты (Results)

- Отдельный экран академических результатов.
- Отображение оценок по дисциплинам.
- Представление GPA.
- Информация об учебных кредитах.

*Примечание: результаты и оценки используются в демонстрационных целях.*

### 👨‍🎓 Студенты (Students)

- Отдельный экран для отображения списка студентов.
- Раздел предназначен для использования в режиме преподавателя.

### 📝 Задания (Assignments)

- Отдельный экран для учебных заданий.
- Раздел для организации и просмотра информации о заданиях.

### 🏆 Достижения (Achievements)

- Отдельный раздел достижений.
- Экран для отображения академических и других достижений пользователя.

### 🔔 Уведомления (Notifications)

- Отдельный экран уведомлений.
- Раздел для отображения информации о событиях и сообщениях приложения.

### ⚙️ Настройки (Settings)

- Экран настроек приложения.
- Управление уведомлениями.
- Выбор светлой и тёмной темы.
- Сохранение пользовательских настроек с помощью AsyncStorage.

### 🛡️ Конфиденциальность (Privacy)

- Настройка видимости профиля.
- Управление отображением электронной почты.
- Параметры конфиденциальности.
- Информация о политике конфиденциальности.

*Примечание: настройки конфиденциальности изменяют состояние интерфейса приложения и пока не связаны с полноценной серверной системой защиты данных.*

## 🧭 Навигация приложения

Для перехода между экранами используется React Navigation.

Основная структура навигации включает:

- Login — вход в систему.
- Register — регистрация.
- ForgotPassword — восстановление пароля.
- Home — главная страница.
- Courses — список учебных курсов.
- CourseDetails — подробная информация о курсе.
- Schedule — расписание занятий.
- Results — академические результаты студента.
- Students — список студентов для преподавателя.
- Profile — профиль пользователя.

В зависимости от роли пользователя отображается соответствующий раздел: **Results** для студента или **Students** для преподавателя.

Для основных разделов приложения используется нижняя панель навигации (Bottom Tab Navigation).

## 🛠️ Используемые технологии

**React Native** — разработка мобильного приложения.

**Expo** — запуск, настройка и тестирование приложения.

**TypeScript** — типизация и повышение надёжности кода.

**React Navigation** — навигация между экранами.

**AsyncStorage** — локальное сохранение пользовательских данных и настроек.

**Expo Image Picker** — выбор фотографии из галереи устройства.

**Expo File System** — сохранение фотографии во внутренней памяти приложения.

**React Hooks** — управление состоянием и логикой компонентов.

**WordPress REST API** — получение новостей ALT University.

**Visual Studio Code** — среда разработки.

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/semenbaierasyl8707-lang/University-App-Ui-Concept--Community.git
```

### 2. Переход в папку проекта

```bash
cd University-App-Ui-Concept--Community
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Запуск Expo

```bash
npx expo start
```

### 5. Запуск приложения

После запуска Expo можно открыть приложение через Expo Go на мобильном устройстве или с помощью Android Emulator.

## 🎯 Цель проекта

Основная цель UniversityApp — объединить необходимые университетские функции в одном мобильном приложении и упростить взаимодействие студентов и преподавателей с учебной информацией.

В процессе разработки проекта были получены практические навыки работы с React Native, TypeScript, Expo, React Navigation, REST API, локальным хранилищем данных и созданием многоэкранных мобильных приложений.

Проект также демонстрирует применение компонентного подхода, повторное использование UI-компонентов и организацию структуры мобильного приложения.
