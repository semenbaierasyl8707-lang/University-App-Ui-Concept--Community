# 🎓 UniversityApp — Университетті басқаруға арналған мобильді қосымша

**UniversityApp** — студенттер мен оқытушылардың университет өмірін жеңілдетуге арналған мобильді қосымша. Қосымша арқылы академиялық ақпаратты көруге, сабақ кестесімен танысуға, оқу нәтижелерін тексеруге және жеке баптауларды басқаруға болады.

Жоба React Native және Expo технологиялары арқылы әзірленген.

## ✨ Қосымшаның негізгі мүмкіндіктері

### 🔐 Тіркелу және жүйеге кіру

* Жаңа пайдаланушыны тіркеу.
* Жүйеге кіру беті.
* Пайдаланушының жеке ақпаратын сақтау.
* Студент және оқытушы рөлдерін қолдау.

### 👤 Профиль

* Жеке ақпаратты көрсету.
* Студент немесе оқытушы рөлін көрсету.
* Академиялық статистиканы қарау.
* Қосымша баптауларына өту.
* Жетістіктер бөлімін ашу.
* Құпиялылық баптауларына өту.
* Жүйеден шығу.

### ⚙️ Баптаулар (Settings)

* Хабарландыруларды қосу және өшіру.
* Ашық және қараңғы режимді таңдау.
* Баптауларды AsyncStorage арқылы сақтау.

### 🛡️ Құпиялылық (Privacy)

* Профильдің көрінуін басқару.
* Электрондық поштаның көрінуін басқару.
* Деректерді қорғау параметрі.
* Құпиялылық саясаты туралы ақпарат.

*Ескерту: Құпиялылық параметрлері әзірге экран ішіндегі күйді ғана өзгертеді. Олар нақты серверлік қауіпсіздік жүйесіне қосылмаған.*

### 📅 Сабақ кестесі (Schedule)

* Сабақ кестесіне арналған жеке экран.
* Оқу кестесі туралы ақпаратты қарау.

### 📊 Оқу нәтижелері (Results)

* Студенттердің оқу нәтижелерін көрсетуге арналған бөлім.

### 👨‍🎓 Студенттер (Students)

* Студенттер тізімін көрсету.
* Студенттер туралы ақпаратпен танысу.

### 🏆 Жетістіктер (Achievements)

* Академиялық жетістіктерді көрсету.
* Жетістіктер бөліміне жеке қол жеткізу.

### 🔔 Хабарландырулар (Notifications)

* Хабарландыруларға арналған жеке экран.

## 🛠️ Қолданылған технологиялар

* **React Native** — мобильді қосымша әзірлеу.
* **Expo** — қосымшаны іске қосу және тестілеу.
* **TypeScript** — бағдарламалау тілінің типтерін басқару.
* **AsyncStorage** — жергілікті деректерді сақтау.
* **React Hooks** — компоненттердің күйі мен өмірлік циклін басқару.
* **Visual Studio Code** — бағдарламалау ортасы.

## 🚀 Жобаны іске қосу

**1. Репозиторийді компьютерге жүктеу:**

```bash
git clone https://github.com/semenbaierasyl8707-lang/University-App-Ui-Concept--Community.git
```

**2. Жоба бумасына өту:**

```bash
cd University-App-Ui-Concept--Community
```

**3. Қажетті пакеттерді орнату:**

```bash
npm install
```

**4. Expo серверін іске қосу:**

```bash
npx expo start
```

**5. Қосымшаны Expo Go немесе Android эмуляторы арқылы ашу.**
